# BetterInabanga 🇵🇭

> **Digital Civic Transparency & Public Services Portal for the Municipality of Inabanga, Bohol**  
> Built under the [BetterGov.ph LGU Directory Initiative](https://lgu.bettergov.ph/GUIDE) and modeled after [BetterSolano](https://github.com/BetterSolano/bettersolano).

---

## 🌟 Overview

**BetterInabanga** is a community-maintained, open-source digital civic portal that makes local government information—elected officials, annual budgets, 20% development fund infrastructure projects, citizen's charter services, 50 barangays, and 24/7 disaster hotlines—easily accessible to all Inabangnons and the public.

---

## 🚀 Key Features

- **24/7 Emergency Dispatch Hotlines:** One-tap dialing for MDRRMO ((038) 510-8164), PNP Inabanga ((038) 512-9039), BFP Fire Station (0927-528-1232), and Bohol TaRSIER 117.
- **Citizen's Charter & Services Guide:** Step-by-step procedures, fees, processing turnaround, and documentary requirements for Civil Registry, Business Permits, Real Property Tax (Amilyar), Social Welfare (AICS), Rural Health Unit (RHU), and Fisherfolk Boat Licensing.
- **Elected Leadership Directory (2025–2028 Term):** Up-to-date profiles of Municipal Mayor Hon. Dexter M. Ancla, Municipal Vice Mayor Hon. Hermogenes C. Cenabre, Jr., Sangguniang Bayan councilors, and municipal department heads.
- **Full Disclosure Policy (FDP) & Budget Visualizer:** Transparent breakdown of the ₱248.6M+ annual municipal budget and National Tax Allotment (NTA/IRA), plus real-time monitoring of 20% Municipal Development Fund priority infrastructure projects.
- **50 Barangays Directory:** Searchable index of all 50 barangays with distance from Poblacion, key characteristics, and community highlights.
- **Citizen Feedback & Civic Inquiries:** Interactive form for citizens to submit suggestions, service commendations, or public information requests.

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/) (Zero-configuration ready)

---

## 💻 Getting Started Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the local development server:**
   ```bash
   npm run dev
   ```

3. **Open the portal:**
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```

---

## 🚢 Deploying to Vercel

This repository is pre-configured with `vercel.json` for zero-config deployment:

1. Push your repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of BetterInabanga Next.js portal"
   git remote add origin https://github.com/YOUR_USERNAME/betterinabanga.git
   git push -u origin main
   ```
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import the `betterinabanga` repository.
4. Click **Deploy** (Vercel automatically detects Next.js and builds the project).
